# Aoife Hughes — personal website

Static site for [dr-hughes.github.io](https://dr-hughes.github.io), built
with [Hugo](https://gohugo.io) and the
[hugo-paper](https://github.com/nanxiaobei/hugo-paper) theme (MIT), vendored
under `themes/hugo-paper/`. The look is Nord Light: white page, Snow Storm
greys, Polar Night text, Frost links and gentle Aurora accents.

## Layout

- `content/english/` — sections: `about/`, `contact/`, `teaching/`
  (type `teaching-resources`, the filterable lesson table; `teaching/slides/`
  is the browser-deck hub, type `teaching-slides`), `research/`, `pages/`
  (privacy policy via permalinks)
- `config.toml` — single-file site config (title, menu, params, permalinks)
- `data/teaching_resources.yaml` — one entry per lesson (subject, level,
  year, topic, slides, worksheets), rendered by
  `layouts/teaching-resources/list.html`; `data/teaching_slides.yaml` feeds
  the deck hub
- `layouts/` — overrides of the theme: `index.html` (home), `_default/list.html`
  (plain section pages), the two teaching layouts, `partials/header.html`
  (no dark-mode toggle) and `partials/footer.html`
- `assets/custom.css` — all colours and component styles (see note below)
- `static/` — served verbatim: `teaching/<lesson>/` (PPTX and worksheets),
  `slides/` (see submodule below), `images/`, `figures/`, `subfiles/`, and
  standalone pages (`demo.html`, `genetic.html`, `mapmate.html`,
  `pyescape.html`)
- `public/` — committed build output, served read-only by the Terrasen
  `html-host` container (see `docs/html-host.md` in the containers repo).
  It is not regenerated by every commit; building it needs the `static/slides`
  submodule checked out or the decks are dropped.

## Building

Requires **Hugo extended** (CI pins 0.168.0)
— no Node, no Go, no Hugo modules.

```bash
git submodule update --init static/slides   # private repo; needs SSH access
hugo --gc --minify --forceSyncStatic
```

Output lands in `public/`. Serve locally with `hugo server` if desired.

## Deploying

`.github/workflows/gh-pages.yml` builds on push to `main` with Hugo
`0.168.0` extended and deploys `public/` to GitHub Pages. The workflow
checks out submodules with a read-only deploy key for the private
`Dr-Hughes/slides` repo, so the teaching decks are copied into the
public site — keep that in mind when adding decks.

## Theme notes

hugo-paper ships a prebuilt Tailwind stylesheet, and its build flattened
cascade layers with `:not(#\#)` specificity hacks (up to five deep). Plain
selectors therefore lose to it, so `assets/custom.css` nests every rule under
`:root` plus six `:not(#\#)`. Keep new rules inside that block. The site has
no dark mode on purpose.

Teaching files were sanitised when imported (speaker notes blanked, author
metadata cleared, school and colleague names removed). Do the same for new
files before adding them to `static/teaching/`.
