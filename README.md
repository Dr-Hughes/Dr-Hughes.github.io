# dr-hughes.github.io

This site has moved to **[dr-hughes.uk](https://dr-hughes.uk/)**.

`site/` is published to GitHub Pages as-is (`.github/workflows/pages.yml`):

- Every old page redirects to its new home: `/`, `/about/`, `/research/`, `/contact/`, `/teaching/`, `/teaching/pyodle/`,
  each old lesson folder `/teaching/<id>/` to its lesson page on dr-hughes.uk, and anything else via `404.html`.
- The old research demo pages stay where they were: `genetic.html`, `pyescape.html`, `mapmate.html`, `demo.html`
  (with `figures/` and `subfiles/`) and the MMO Simulator docs in `mmo-simulator/`.

Teaching materials (slides, worksheets, code) live in
[Dr-Hughes/Teaching-Materials](https://github.com/Dr-Hughes/Teaching-Materials).
